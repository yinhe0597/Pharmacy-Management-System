# 18 跟诊护士与药房护士角色设计（角色细化）

> 目的：将原单一「护士」角色，按药房 + 诊疗实际业务细化为 **跟诊护士（诊室护士）** 与 **药房护士** 两个角色，
> 使患者信息管理、核对医嘱、医疗耗材补发登记、辅助核对收费等职责各归其位，前后端配合更清晰。
> 原则：**先设计 → 后端/数据库配套 → 前端开发**（本文为设计与配套落地的依据）。

---

## 一、角色定位

| 角色 | 常量 | 工作场景 | 核心职责 |
|------|------|---------|---------|
| 跟诊护士 | `clinic_nurse` | 诊室（随诊医生） | 患者信息管理、核对医嘱、辅助录入医嘱/诊疗项目、诊疗执行计费 |
| 药房护士 | `pharmacy_nurse` | 药房 | 药品/库存查询、耗材领用与补发登记、处方执行辅助、辅助核对收费、药学服务 |

> 原 `nurse` 角色由 `pharmacy_nurse` 承接（其权限本就是「处方执行/药学服务/药品查询」），
> 新增 `clinic_nurse` 承接诊室侧职责。

## 二、职责与功能清单

### 2.1 跟诊护士 `clinic_nurse`

| 功能 | 说明 | 后端配套 |
|------|------|---------|
| 患者信息管理 | 建档、更新、查询患者档案与过敏史 | `patients` 写（新增 PatientAdmin 组） |
| 核对医嘱 | 医生开立后，核对诊断/患者/项目一致性，留痕 | 新增 `POST /prescriptions/{id}/verify-order`（写审计日志，不改状态） |
| 辅助录入医嘱/处方草稿 | 协助医生录入，医生最终确认 | 处方开立（ClinicalStaff 组） |
| 诊疗项目执行 | 手法复位/注射/检查等执行并登记 | `clinical-services` 查看 + 计费录入 |
| 辅助收费核对 | 核对计费记录是否准确 | 计费查看（Billing 组） |

### 2.2 药房护士 `pharmacy_nurse`

| 功能 | 说明 | 后端配套 |
|------|------|---------|
| 药品/库存查询 | 检索药品与库存（含可用量） | 只读（Authed） |
| 医疗耗材补发登记 | 科室领用耗材（手套/纱布/注射器），不计费出库，FEFO 扣减留痕 | `POST /inventory/requisition`（Pharmacy 组） |
| 处方执行辅助 | 调配/发药/核对辅助，配合药师双人核对 | 处方执行（Pharmacy 组） |
| 辅助核对收费 | 发药后核对计费记录，配合药师/财务 | 计费查看（Billing 组） |
| 药学服务 | 咨询/不良反应/指导登记 | 药学服务（Pharmacy 组） |
| 拆零/盘点/空安瓿辅助 | 拆零、盘点、空安瓿回收等药房事务 | 库存写（Pharmacy 组） |

## 五、工作流示例

```
【诊室】跟诊护士：建档(patients) → 辅助医生开方(prescriptions) → 核对医嘱(verify-order)
                    → 执行诊疗项目并计费(charge-records)
【药房】药师/药房护士：审核(review) → 调配(dispense) → 发药确认(confirm-dispense，双人)
                    → 一键计费(from-prescription)
【药房】药房护士：耗材补发登记(requisition) → 辅助核对收费(charge-records 查看)
【财务】报表核对(reports)
```

## 六、后续前端影响

- 登录/菜单：8 角色；跟诊护士菜单 = 患者管理 + 开方/医嘱核对 + 诊疗执行计费；
  药房护士菜单 = 药品查询 + 库存/领用/补发 + 处方执行 + 计费核对 + 药学服务。
- 新增「医嘱核对」操作按钮（处方详情页，pending_review 态、ClinicalStaff 可见）。
- 「耗材补发登记」页面复用领用出库表单（默认 item_type=consumable）。

## 七、验收标准

1. 迁移后登录 `pharmacy_nurse`/`clinic_nurse`（密码 admin123）可正常鉴权；
2. 跟诊护士可建档、录处方草稿、执行 verify-order、录入计费，但不可审核/不可库存写；
3. 药房护士可查询药品、领用/补发耗材、执行处方、查看计费，但不可开方/不可审核/不可患者写；
4. 权限矩阵逐格走查通过（RBAC 403 用例已补：`rbac_integration_test.go`，CI 验证）。
