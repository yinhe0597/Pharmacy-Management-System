# 10 部署运维文档

## 一、部署形态

一期为单体服务，单机部署即可满足药房场景。生产建议：Linux + PostgreSQL 同机或异机，`server.mode=release`。

## 二、环境要求

| 组件 | 版本 | 说明 |
|------|------|------|
| Go | ≥ 1.22 | 编译环境 |
| PostgreSQL | ≥ 14 | 数据库 |

## 三、构建

```bash
CGO_ENABLED=0 go build -trimpath -ldflags "-s -w" -o bin/yaofang ./cmd/server
```

## 四、配置

`configs/config.yaml` 为样例，生产通过环境变量覆盖，避免敏感信息入库：

| 环境变量 | 说明 |
|---------|------|
| `YF_SERVER_PORT` | 端口 |
| `YF_SERVER_MODE` | `release` |
| `YF_DATABASE_HOST/PORT/USER/PASSWORD/NAME` | 数据库连接 |
| `YF_AUTH_JWT_SECRET` | JWT 密钥（生产必改，≥32 字符随机） |

## 五、systemd 服务（Linux）

```ini
# /etc/systemd/system/yaofang.service
[Unit]
Description=Yaofang Pharmacy API
After=network.target postgresql.service

[Service]
ExecStart=/opt/yaofang/bin/yaofang
WorkingDirectory=/opt/yaofang
Environment=YF_DATABASE_PASSWORD=***
Restart=always
RestartSec=3
User=yaofang

[Install]
WantedBy=multi-user.target
```

```bash
systemctl daemon-reload && systemctl enable --now yaofang
```

## 六、数据库备份

```bash
# 每日凌晨备份
pg_dump -U yaofang -h localhost -d yaofang -Fc -f /backup/yaofang_$(date +\%Y\%m\%d).dump

# 恢复
pg_restore -U postgres -d yaofang --clean /backup/yaofang_xxx.dump
```

建议：定时备份 + 异地保留 30 天；变更前先备份。

## 七、升级步骤

1. `git pull` 拉取新版本，审阅新增 `migrations/` 迁移文件。
2. 备份数据库。
3. 执行 `psql -f migrations/NNNNNN_xxx.up.sql`（按版本顺序）。
4. `systemctl restart yaofang`。
5. `curl http://localhost:8080/readyz` 探活。

## 八、运维检查

| 检查 | 方式 |
|------|------|
| 探活 | `GET /healthz`、`GET /readyz` |
| 日志 | 结构化日志输出到 stdout，可接 journald/文件采集 |
| 定时任务 | 观察日志 `scheduler_*` 是否正常执行 |
| 磁盘/连接池 | PostgreSQL 连接数、日志告警 |
