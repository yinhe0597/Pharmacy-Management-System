## 二、关键设计决策

1. **退药回补溯源而非查当前配置库房**：`Return` 先 `GetByID(rec.InventoryID)` 取源行库房，源行已删才回退 `FindByKey`。库房配置变更只影响新业务，老处方退药仍回原库房，账实一致。
2. **通知已读必须按用户隔离**：初版 `is_read` 落通知行会导致一人已读全员消失，改为 `notification_reads` 回执表 + `ON CONFLICT DO NOTHING` 幂等。
3. **归档与备份是两回事**：归档解决在线表膨胀（应用内调度器），备份解决灾难恢复（`backup_db.sh`），两者都要做（docs/10 §12 已注明）。
4. **Raw+Scan 的 SELECT 无法 DryRun 断言**：gORM `Rows()` 在 DryRun 下直接返回 `ErrDryRunModeUnsupported`，回调链不执行；S7 SELECT 口径必须由集成环境覆盖，归档语句走 `Exec` 可断言。
