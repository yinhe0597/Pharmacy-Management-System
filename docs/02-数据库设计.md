# 02 数据库设计

> 数据库：PostgreSQL 14+ ｜ 迁移工具：golang-migrate（SQL 文件）
> 约定：金额一律 `bigint`（分）；数量按「最小发药单位」（拆零单位，无拆零则基本单位）为准（见 §0）。
> 全部表含 `created_at timestamptz not null default now()`；关键表含 `updated_at`；主数据含 `deleted_at`（软删）。

---

## §0 单位与金额约定（先读）

- **金额**：`retail_price` / `purchase_price` 等一律为「分」的整数。
- **基本单位（base_unit）**：一盒 / 一瓶 / 一支，是采购与整盒发药的单位。
- **拆零单位（split_unit）**：一片 / 一粒 / 一支，是拆零发药的最小单位。
- **换算**：`1 基本单位 = drugs.pack_size 拆零单位`。
- **库存数量口径**：
  - 库存行 `is_split=false`：`quantity` 以**基本单位**计数（整盒库存）。
  - 库存行 `is_split=true`：`quantity` 以**拆零单位**计数（拆零柜库存）。
  - 上下限、预警、采购计划统一折算到**拆零单位（LDU）** 比较：
    `可用(LDU) = 整盒行数量×pack_size + 拆零行数量 − 预占(LDU)`。
- **拆零单价**：`split_retail_price = round(retail_price / pack_size)`，四舍五入到分；
  拆零进价同理 `round(purchase_price / pack_size)`。

## §2 建表 DDL（迁移文件 `000001_init.up.sql`）

```sql
-- 1. 系统用户
CREATE TABLE users (
    id            BIGSERIAL PRIMARY KEY,
    username      VARCHAR(50)  NOT NULL UNIQUE,
    password_hash VARCHAR(100) NOT NULL,
    name          VARCHAR(50)  NOT NULL,
    role          VARCHAR(20)  NOT NULL,  -- admin/pharmacist/dispenser/checker/buyer
    phone         VARCHAR(20),
    status        SMALLINT     NOT NULL DEFAULT 1, -- 1启用 0停用
    created_at    TIMESTAMPTZ  NOT NULL DEFAULT now(),
    updated_at    TIMESTAMPTZ  NOT NULL DEFAULT now(),
    deleted_at    TIMESTAMPTZ
);
COMMENT ON COLUMN users.role IS 'admin管理员/pharmacist药师/dispenser调配/checker核对/buyer采购';

-- 2. 药品分类
CREATE TABLE drug_categories (
    id         BIGSERIAL PRIMARY KEY,
    code       VARCHAR(20)  NOT NULL UNIQUE,
    name       VARCHAR(50)  NOT NULL,
    parent_id  BIGINT       NOT NULL DEFAULT 0,   -- 0 为顶级，支持分类树
    sort_order INT          NOT NULL DEFAULT 0,
    status     SMALLINT     NOT NULL DEFAULT 1,
    created_at TIMESTAMPTZ  NOT NULL DEFAULT now(),
    updated_at TIMESTAMPTZ  NOT NULL DEFAULT now()
);

-- 3. 药品主数据（一药多规、一品多商）
CREATE TABLE drugs (
    id                   BIGSERIAL PRIMARY KEY,
    code                 VARCHAR(20)  NOT NULL UNIQUE,   -- 内部药品编码
    generic_name         VARCHAR(100) NOT NULL,          -- 通用名
    brand_name           VARCHAR(100),                   -- 商品名
    dosage_form          VARCHAR(30)  NOT NULL,          -- 剂型
    specification        VARCHAR(100) NOT NULL,          -- 规格，如 0.5g
    manufacturer         VARCHAR(100) NOT NULL,          -- 生产厂家
    approval_number      VARCHAR(50),                    -- 批准文号
    barcode              VARCHAR(50),                    -- 条码
    category_id          BIGINT       REFERENCES drug_categories(id),
    base_unit            VARCHAR(20)  NOT NULL,          -- 基本单位：盒/瓶/支
    split_unit           VARCHAR(20),                    -- 拆零单位：片/粒/ml（空=不可拆零）
    pack_size            INT          NOT NULL DEFAULT 1, -- 每基本单位含拆零单位数（不可拆零时为1）
    is_split_allowed     BOOLEAN      NOT NULL DEFAULT FALSE,
    retail_price         BIGINT       NOT NULL DEFAULT 0, -- 零售价（分/基本单位）
    purchase_price       BIGINT       NOT NULL DEFAULT 0, -- 采购价（分/基本单位）
    split_retail_price   BIGINT       NOT NULL DEFAULT 0, -- 拆零零售价（分/拆零单位）
    split_purchase_price BIGINT       NOT NULL DEFAULT 0, -- 拆零采购价（分/拆零单位）
    antibiotic_level     SMALLINT     NOT NULL DEFAULT 0, -- 0非抗生素 1非限制 2限制 3特殊
    special_control_type SMALLINT     NOT NULL DEFAULT 0, -- 0无 1麻醉 2精神 3毒性 4放射性
    psychotropic_level   SMALLINT     NOT NULL DEFAULT 0, -- 0无 1一类精神 2二类精神
    max_single_dose      BIGINT,                          -- 单次极量（拆零单位）
    max_daily_dose       BIGINT,                          -- 日极量（拆零单位）
    expiry_warning_days  INT          NOT NULL DEFAULT 90, -- 效期预警天数
    py_code              VARCHAR(50),                     -- 拼音码，检索用
    status               SMALLINT     NOT NULL DEFAULT 1, -- 1启用 0停用
    is_frozen            BOOLEAN      NOT NULL DEFAULT FALSE, -- 有关联单据时自动冻结防误删
    remarks              TEXT,
    created_at           TIMESTAMPTZ  NOT NULL DEFAULT now(),
    updated_at           TIMESTAMPTZ  NOT NULL DEFAULT now(),
    deleted_at           TIMESTAMPTZ,
    CONSTRAINT uq_drug UNIQUE (generic_name, specification, manufacturer, dosage_form)
);
CREATE INDEX idx_drugs_generic_name ON drugs (generic_name);
CREATE INDEX idx_drugs_py_code     ON drugs (py_code);
CREATE INDEX idx_drugs_category    ON drugs (category_id);
CREATE INDEX idx_drugs_special     ON drugs (special_control_type);
COMMENT ON COLUMN drugs.is_split_allowed IS '是否允许拆零';
COMMENT ON COLUMN drugs.max_single_dose IS '单次极量，以拆零单位计';

-- 4. 药品配伍禁忌
CREATE TABLE drug_interactions (
    id          BIGSERIAL PRIMARY KEY,
    drug_a_id   BIGINT NOT NULL REFERENCES drugs(id),
    drug_b_id   BIGINT NOT NULL REFERENCES drugs(id),
    level       SMALLINT NOT NULL,            -- 1禁忌 2慎用 3注意
    description VARCHAR(500),
    created_at  TIMESTAMPTZ NOT NULL DEFAULT now(),
    CONSTRAINT uq_interaction UNIQUE (drug_a_id, drug_b_id)
);
CREATE INDEX idx_interaction_a ON drug_interactions (drug_a_id);
CREATE INDEX idx_interaction_b ON drug_interactions (drug_b_id);

-- 5. 供应商
CREATE TABLE suppliers (
    id                BIGSERIAL PRIMARY KEY,
    code              VARCHAR(20)  NOT NULL UNIQUE,
    name              VARCHAR(100) NOT NULL,
    contact_person    VARCHAR(50),
    phone             VARCHAR(20),
    address           VARCHAR(200),
    qualification_no  VARCHAR(50),   -- 资质证号
    status            SMALLINT NOT NULL DEFAULT 1, -- 1启用 0停用
    remarks           TEXT,
    created_at        TIMESTAMPTZ NOT NULL DEFAULT now(),
    updated_at        TIMESTAMPTZ NOT NULL DEFAULT now(),
    deleted_at        TIMESTAMPTZ
);

-- 6. 药品-供应商供货关系（一品多商、供货价）
CREATE TABLE drug_suppliers (
    id               BIGSERIAL PRIMARY KEY,
    drug_id          BIGINT NOT NULL REFERENCES drugs(id),
    supplier_id      BIGINT NOT NULL REFERENCES suppliers(id),
    is_default       BOOLEAN NOT NULL DEFAULT FALSE, -- 默认供应商
    purchase_price   BIGINT,   -- 该供应商供货价（分/基本单位）
    last_purchase_at TIMESTAMPTZ,
    status           SMALLINT NOT NULL DEFAULT 1,
    created_at       TIMESTAMPTZ NOT NULL DEFAULT now(),
    updated_at       TIMESTAMPTZ NOT NULL DEFAULT now(),
    CONSTRAINT uq_drug_supplier UNIQUE (drug_id, supplier_id)
);

-- 7. 库存地点（多级库存）
CREATE TABLE inventory_locations (
    id         BIGSERIAL PRIMARY KEY,
    code       VARCHAR(20) NOT NULL UNIQUE,
    name       VARCHAR(50) NOT NULL,
    type       SMALLINT    NOT NULL, -- 1药库 2药房 3科室
    parent_id  BIGINT      NOT NULL DEFAULT 0,
    is_active  BOOLEAN     NOT NULL DEFAULT TRUE,
    created_at TIMESTAMPTZ NOT NULL DEFAULT now(),
    updated_at TIMESTAMPTZ NOT NULL DEFAULT now()
);
COMMENT ON TABLE inventory_locations IS '多级库存：药库、药房、科室基数药';

-- 8. 库存上下限设置（单位：拆零单位 LDU）
CREATE TABLE drug_stock_settings (
    id            BIGSERIAL PRIMARY KEY,
    drug_id       BIGINT NOT NULL REFERENCES drugs(id),
    location_id   BIGINT NOT NULL REFERENCES inventory_locations(id),
    min_quantity  BIGINT NOT NULL DEFAULT 0,  -- 下限（LDU）
    max_quantity  BIGINT NOT NULL DEFAULT 0,  -- 上限（LDU），0=不限
    reorder_qty   BIGINT NOT NULL DEFAULT 0,  -- 建议补货量
    is_enabled    BOOLEAN NOT NULL DEFAULT TRUE,
    created_at    TIMESTAMPTZ NOT NULL DEFAULT now(),
    updated_at    TIMESTAMPTZ NOT NULL DEFAULT now(),
    CONSTRAINT uq_stock_setting UNIQUE (drug_id, location_id)
);

-- 9. 库存（批号+效期维度，核心表）
CREATE TABLE inventory (
    id                BIGSERIAL PRIMARY KEY,
    drug_id           BIGINT NOT NULL REFERENCES drugs(id),
    location_id       BIGINT NOT NULL REFERENCES inventory_locations(id),
    batch_no          VARCHAR(50) NOT NULL,   -- 批号
    expiry_date       DATE        NOT NULL,   -- 效期
    quantity          BIGINT      NOT NULL DEFAULT 0,   -- 当前数量（is_split=false按基本单位，true按拆零单位）
    reserved_quantity BIGINT      NOT NULL DEFAULT 0,   -- 已预占数量（同口径）
    is_split          BOOLEAN     NOT NULL DEFAULT FALSE, -- 是否拆零批次
    unit_price        BIGINT      NOT NULL DEFAULT 0,   -- 批次进价（分，同口径单位）
    received_at       TIMESTAMPTZ NOT NULL DEFAULT now(), -- 入库时间（FEFO 次级排序）
    status            SMALLINT    NOT NULL DEFAULT 1,   -- 1正常 2过期锁定 3手动锁定
    created_at        TIMESTAMPTZ NOT NULL DEFAULT now(),
    updated_at        TIMESTAMPTZ NOT NULL DEFAULT now(),
    CONSTRAINT uq_inventory UNIQUE (drug_id, location_id, batch_no, expiry_date, is_split)
);
CREATE INDEX idx_inventory_drug_loc   ON inventory (drug_id, location_id);
CREATE INDEX idx_inventory_expiry     ON inventory (expiry_date) WHERE status = 1;
CREATE INDEX idx_inventory_available  ON inventory (drug_id, location_id, expiry_date) WHERE status = 1;
COMMENT ON COLUMN inventory.quantity IS '数量口径：is_split=false按基本单位(盒)，true按拆零单位(片)';
COMMENT ON COLUMN inventory.reserved_quantity IS '已预占数量，可用=quantity-reserved_quantity';

-- 10. 库存流水（每一笔变动可追溯）
CREATE TABLE inventory_transactions (
    id               BIGSERIAL PRIMARY KEY,
    transaction_no   VARCHAR(30) NOT NULL UNIQUE,   -- 业务流水号
    drug_id          BIGINT NOT NULL REFERENCES drugs(id),
    location_id      BIGINT NOT NULL REFERENCES inventory_locations(id),
    batch_no         VARCHAR(50),
    expiry_date      DATE,
    quantity         BIGINT NOT NULL,               -- 有符号：正=入，负=出
    is_split         BOOLEAN NOT NULL DEFAULT FALSE,
    before_quantity  BIGINT,                        -- 变动前数量（同口径）
    after_quantity   BIGINT,                        -- 变动后数量
    txn_type         VARCHAR(20) NOT NULL,          -- 见下表
    ref_type         VARCHAR(30),                   -- 关联单据类型：purchase_receipt/prescription/stocktake/transfer_order...
    ref_id           BIGINT,                        -- 关联单据ID
    operator_id      BIGINT,
    operator_name    VARCHAR(50),
    remarks          VARCHAR(200),
    created_at       TIMESTAMPTZ NOT NULL DEFAULT now()
);
CREATE INDEX idx_inv_txn_drug_time ON inventory_transactions (drug_id, created_at);
CREATE INDEX idx_inv_txn_ref       ON inventory_transactions (ref_type, ref_id);
CREATE INDEX idx_inv_txn_type      ON inventory_transactions (txn_type);
COMMENT ON TABLE inventory_transactions IS '库存流水，进销存汇总与追溯的唯一依据';

-- 流水类型（txn_type）
-- purchase_in       采购入库        stock_in        其他入库
-- stock_out         出库/领用        dispense        发药
-- dispense_return   退药入库        stocktake_adjust 盘点调整
-- transfer_out      调拨出          transfer_in      调拨入
-- split_out         拆零出(整盒)    split_in         拆零入(拆零)
-- waste             报损            reservation      预占(仅记账不冲数量)
-- reservation_release 释放预占(仅记账)

-- 11. 库存预占记录
CREATE TABLE stock_reservations (
    id               BIGSERIAL PRIMARY KEY,
    reservation_no   VARCHAR(30) NOT NULL UNIQUE,
    ref_type         VARCHAR(30) NOT NULL,  -- prescription
    ref_id           BIGINT NOT NULL,       -- 处方ID
    item_id          BIGINT,                -- 处方明细ID
    inventory_id     BIGINT NOT NULL REFERENCES inventory(id),
    drug_id          BIGINT NOT NULL,
    location_id      BIGINT NOT NULL,
    batch_no         VARCHAR(50) NOT NULL,
    expiry_date      DATE NOT NULL,
    is_split         BOOLEAN NOT NULL DEFAULT FALSE,
    quantity         BIGINT NOT NULL,       -- 预占数量（同口径）
    status           VARCHAR(20) NOT NULL DEFAULT 'active', -- active/consumed/released
    created_at       TIMESTAMPTZ NOT NULL DEFAULT now(),
    released_at      TIMESTAMPTZ
);
CREATE INDEX idx_reservation_ref ON stock_reservations (ref_type, ref_id, status);
CREATE INDEX idx_reservation_inv ON stock_reservations (inventory_id, status);

-- 18. 处方
CREATE TABLE prescriptions (
    id                     BIGSERIAL PRIMARY KEY,
    prescription_no        VARCHAR(30) NOT NULL UNIQUE,
    -- 简易患者信息（一期），二期接入完整患者档案（见 05 文档）
    patient_id             BIGINT,               -- 二期关联 patients.id
    patient_name           VARCHAR(50) NOT NULL,
    patient_gender         VARCHAR(10),
    patient_age            VARCHAR(10),          -- 自由文本（X岁/X月）
```

## §3 关键索引与查询设计

| 高频查询 | 索引策略 |
|---------|---------|
| 某药品各库房可用库存 | `idx_inventory_drug_loc` + 状态过滤 |
| 发药选批次（FEFO） | `SELECT ... WHERE drug_id=? AND location_id=? AND status=1 AND quantity>reserved_quantity ORDER BY expiry_date, received_at` 命中 `idx_inventory_available` |
| 近效期扫描 | `idx_inventory_expiry`（部分索引，只含正常库存） |
| 进销存汇总（期间） | 对 `inventory_transactions` 按 `(drug_id, created_at)` 聚合，命中 `idx_inv_txn_drug_time` |
| 处方状态查询 | `idx_prescription_status` |

## §4 数据一致性约束

1. **负库存禁止**：所有扣减 `UPDATE ... WHERE quantity >= 扣减量`，并检查 `RowsAffected`。
2. **预占不超过数量**：`reserved_quantity <= quantity` 恒成立，由行锁事务保证。
3. **批号必填**：收货、发药、退药全部绑定批次，不允许无批次流转。
4. **过期批次禁发**：`expiry_date < current_date` 的库存行状态自动置 `2`，发药查询排除。
5. **软删除与冻结**：药品/供应商有下游单据时置 `is_frozen=true` 而非删除；无下游才允许软删。
6. **外键方向**：流水/记录表引用主数据用物理外键（`REFERENCES`），报表聚合不受影响。
