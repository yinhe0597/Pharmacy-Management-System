# 04 领域模型与业务规则

> 本文档是业务正确性的唯一事实来源。实现与测试均以本文档为准。

---

## §1 金额与单位规则

### 1.1 金额

- 所有金额字段为 `int64`，单位「分」，禁止使用浮点数。
- 计算一律整数运算；唯一需要四舍五入处为拆零价换算：
  - `split_retail_price   = round(retail_price   / pack_size)`
  - `split_purchase_price = round(purchase_price / pack_size)`
  - 四舍五入规则（半入）：`round(a/b) = (a + b/2) / b` 整数除法取整，落到个位分。
- 行金额 `amount = quantity × unit_price`（均为整数，精确无舍入）。
- 处方 `total_amount = Σ 行 amount`。

### 1.2 单位

| 概念 | 定义 | 示例 |
|------|------|------|
| 基本单位 base_unit | 采购、整盒发药单位 | 盒 |
| 拆零单位 split_unit | 拆零发药最小单位 | 粒 |
| pack_size | 1 基本单位 = pack_size 拆零单位 | 24 |
| LDU（最小发药单位） | 可拆零药 = split_unit；不可拆零 = base_unit | 粒 / 盒 |

- 库存行 `is_split=false`：数量以基本单位计；`is_split=true`：数量以拆零单位计。
- 处方/上下限/预警/报表统一折算 LDU：`LDU = 整盒行数量×pack_size + 拆零行数量 − 预占(LDU)`。

## §2 药品主数据规则

- **一药多规**：同一通用名可有多条规格不同的记录（`drugs.specification` 不同）。
- **一品多商**：同一通用名+规格+剂型可对应多个厂家记录；唯一约束为
  `(generic_name, specification, manufacturer, dosage_form)`，精确重复才被拒绝。
- **状态**：`status=1 启用` 可参与采购/发药；`status=0 停用` 不允许新建处方明细，
  但历史处方可正常追溯。
- **冻结**：药品存在下游单据（库存批次/采购/处方/流水）时，禁止硬删除，自动转 `is_frozen=true`。
- **管控标记**：
  - 抗生素分级 `antibiotic_level`：0 非抗生素 / 1 非限制 / 2 限制 / 3 特殊。
  - 特殊管制 `special_control_type`：0 无 / 1 麻醉 / 2 精神 / 3 毒性 / 4 放射性。
  - 精神分级 `psychotropic_level`：1 一类 / 2 二类。
  - 标记为麻醉/精神/毒性/放射性的药品：处方录入强制走专用流程（§7）。

## §3 库存领域规则

### 3.1 库存行

- 一个库存行 = `(drug_id, location_id, batch_no, expiry_date, is_split)`，唯一约束见 §2 表 9。
- 数量恒非负；`可用 = quantity − reserved_quantity`。
- 状态：`1 正常` / `2 过期锁定` / `3 手动锁定`。

### 3.2 入库（采购收货 / 其他入库）

- 入库即绑定批号与效期：`batch_no`、`expiry_date` 必填。
- 同批号多次入库：已存在对应库存行则累加 `quantity` 与 `received_at`（取最早），否则新建。
- 入库写流水 `purchase_in` / `stock_in`，记录变动前后数量。
- 到货效期早于收货日 + 预警天数时给出提示（可配置为拦截或放行+标记）。

### 3.3 出库与 FEFO 发药

- 发药批次选择规则 **FEFO（先近效期先出）**：
  `ORDER BY expiry_date ASC, received_at ASC`（同效期先出先入）。
- 优先消耗拆零库存，其次整盒库存（避免长期积压拆零库存）。
- 每批发药都写 `prescription_dispense_records`，记录 `(batch_no, expiry_date, quantity, unit_price)`。

### 3.4 拆零

- 前置条件：`drugs.is_split_allowed=true`，且仅可拆「未被预占」的整盒（否则破坏 `quantity>=reserved`）。
- 两类操作（见 [13-药品拆零方案.md](13-药品拆零方案.md)）：
  - **按盒拆** `Split(inventoryID, packs)`：`packs` 盒整入拆零行。
  - **按片拆** `SplitUnits(inventoryID, boxes, units, damaged)`：开盒零头入账 + 破损报损，
    校验 `units + damaged == boxes × pack_size`（账目平齐），破损记 `split_out` 备注。
- 事务内完成：整盒行扣减 `boxes` → 拆零行累加 `units`（不存在则新建）→ 两条流水 `split_out` / `split_in`。
- **拆零行进价 = round(整盒行批次实际进价 / pack_size)**，保证批次成本一致（不用主数据价）。
- 拆零零售价：默认 `round(retail_price / pack_size)`，允许显式配置覆盖（分摊损耗），拆零进价恒公式推导。
- 拆零缺货时提示「整盒可用 X 盒，可拆零后重新提交」。

### 3.5 调拨

- `from` 库房扣减 + `to` 库房累加在同一事务完成，两条流水 `transfer_out` / `transfer_in`。
- 仅允许同药品同批次同口径移动；`from` 库房可用量不足则整体失败。

### 3.6 预占 / 释放 / 实扣（关键正确性）

| 操作 | 前置状态 | 事务内行为 |
|------|---------|-----------|
| 预占 ReserveStock | 处方提交审核 | 锁库存行 → `reserved_quantity += n` → 写 `stock_reservations(active)` |
| 释放 CancelReservation | 退方/驳回/作废 | 锁库存行 → `reserved_quantity -= n` → 预占记录置 `released` |
| 实扣 Dispense | 发药确认 | 锁库存行 → `quantity -= n`、`reserved_quantity -= n` → 预占记录置 `consumed` → 流水 |

- 每次操作重新校验 `available >= n`，条件更新 `WHERE quantity >= ?` 兜底并发。
- 预占失败（库存不足）时返回明细（哪个药品缺多少），允许处方继续流转，
  但**调配环节必须重新校验**，仍不足则不允许进入发药确认。

### 3.7 效期与过期

- 近效期判定：`expiry_date <= today + drugs.expiry_warning_days` 且 `status=1` → 生成 `stock_alerts(expiry)`。
- 过期锁定：每日定时任务将 `expiry_date < today` 的行置 `status=2`；发药查询排除 `status != 1`。
- 过期批次不参与任何出库；盘点可正常记录其数量。

### 3.8 上下限预警

- 比较口径 LDU：`可用(LDU) >= drug_stock_settings.max_quantity` 不预警；
  `可用(LDU) <= min_quantity` → 生成 `stock_alerts(below_min)`。
- 采购计划建议量：`max(0, max_quantity − 可用(LDU))`，结合近 30 日日均消耗向上取整。

### 3.9 盘点

- 支持周期盘点（全库）与动态盘点（指定药品/批次）。
- 盘点期间（`counting`）该库房禁止入库/出库/调拨（`2005 盘点进行中`）。
- 差异调整走 `stocktake_adjust` 流水，差异必须由复核人确认，一次盘点只能 adjust 一次。

## §4 处方状态机

```
                    ┌──────────── pending_review（待审核）
                    │    submit（录入时预占库存）
                    │
        ┌───────────┴───────────┐
  review pass               review reject
        │                        │
        ▼                        ▼
 reviewed_passed ◄─────── reviewed_rejected
        │                    （修改后可重新 submit）
        ▼
   dispensing（调配中，按 FEFO 分配批次）
        │
        ▼
     dispensed（已发药，实扣库存）
        │
        ▼
     returned（已退药，支持整方/部分）
```
```
取消路径：pending_review / reviewed_passed / reviewed_rejected → cancelled（释放预占）
```

| 状态 | 可执行操作 | 前置条件 |
|------|-----------|---------|
| pending_review | submit / cancel / update | 明细有效、药品启用 |
| reviewed_passed | dispense / cancel | 已通过审核 |
| dispensing | confirm-dispense / cancel(释放) | 批次分配完成 |
| dispensed | return | 实扣完成 |
| returned | —（终态） | — |

- 每次状态变更写 `prescription_audit_logs`。
- 状态流转只允许通过 `PrescriptionService` 方法触发；Handler 不可直接改状态。
- 并发保护：`SELECT ... FOR UPDATE` + `version` 乐观锁（见架构文档 §4.2）。

## §5 处方审核规则

| 检查 | 规则 | 违规级别 | 行为 |
|------|------|---------|------|
| 配伍禁忌 | `drug_interactions` 中处方内任意两药存在 `level=1 禁忌` | 拦截 | `3003` |
| 配伍慎用 | `level=2 慎用` | 提示 | 审核人可备注通过 |
| 极量检查 | `single_dose × 频次 ≤ max_daily_dose`；`single_dose ≤ max_single_dose` | 拦截 | `3002` |
| 重复用药 | 处方内存在同通用名（或同药理分类）多行 | 提示 | 备注确认后通过 |
| 特殊药品必填 | 麻精处方 `patient_card_no`、诊断必填 | 拦截 | `4001` |
| 抗生素分级 | 限制/特殊级抗生素按院感规则（一期仅记录，不做审批流） | 记录 | 审计日志 |

- 审核结果（通过/驳回 + 理由）写入 `prescription_audit_logs`，`reviewed_at` 记时。

## §6 发药与退药

### 6.1 发药确认

- 同一事务：校验处方状态=dispensing → 逐条核销预占并实扣库存 →
  写 `prescription_dispense_records` → 更新 item 已发数量 → 处方状态=dispensed，
  记录 `checker_id`（核对发药药师）与 `dispensed_at`。
- 特殊处方（麻醉/精神/毒性/放射性）额外写 `special_drug_ledgers(dispense)`。
- 实扣按发药记录逐批次执行，任一批次失败则整体回滚。

### 6.2 退药

- 仅 `dispensed` 状态可退；支持整方退回与部分退药。
- 退药按原 `prescription_dispense_records` 的批次回补库存（同批号、同口径）。
- 事务：回补库存 → 写流水 `dispense_return` → 更新 item/prescription 状态与数量。
- 退药后库存行仍参与效期/上下限管理；过期批次不允许退入（回补到过期批按报损处理，需人工）。
- 部分退：item `returned_quantity > 0`；全部退：处方主状态 `returned`。

### 6.3 计价快照

- 单价在**录入时**从 `drugs` 快照到 `prescription_items.unit_price`（整盒发药按盒价折算 LDU，
  拆零发药按 `split_retail_price`）；金额 `amount = quantity × unit_price`。
- 退药金额按原发药记录单价计算，不重算。

## §7 特殊药品「五专」管理

对 `special_control_type ∈ {麻醉, 精神}` 的药品：

| 五专 | 落点 | 实现 |
|------|------|------|
| 专人负责 | 用户角色 | 发药/核对必须为药师角色 |
| 专柜加锁 | 库存地点 | 系统内用独立库房编码 `麻精专柜`，无系统外强制 |
| 专用处方 | prescriptions | `prescription_type ∈ {1麻醉,2精神}` + 必填卡号/身份证、诊断 |
| 专用账册 | special_drug_ledgers | 每次发药/退药/空安瓿回收自动登记 |
| 专册登记 | ampoule_returns | 空安瓿回收登记并与处方关联 |

补充规则：
- 麻精处方发药采用「调配药师 + 核对药师」双人签名（`dispensing_pharmacist_id` / `checker_id`）。
- 一类精神与麻醉药品限制单张处方剂量（常量可配，默认麻醉 ≤3 日量、一类精神 ≤3 日量、二类精神 ≤7 日量）。
- 空安瓿回收数与发药数联动核对，差异记录备注待处理。

## §8 报表口径

| 报表 | 口径 |
|------|------|
| 进销存汇总 | 期间 `期初(期初前的流水汇总) + Σ入 − Σ出 = 期末`，按 `(drug, location)` 聚合，统一折算 LDU |
| 效期分析 | 按 3/6/12 个月内到期、已过期分档统计数量（LDU） |
| 特殊药品使用统计 | 按药/批号/月度聚合 `special_drug_ledgers` |
| 调配工作量 | 按 `prescription_dispense_records.dispensed_by` 与日期聚合处方数与件数 |

报表数据来源为 `inventory_transactions` 与 `special_drug_ledgers`（不可直接从库存当前值推导期间变化）。
