## 项目
- **定位**：药房进销存 + 处方调配系统。后端 Go 1.22 + Gin + GORM + PostgreSQL 14 + swaggo + JWT + robfig-cron；前端 Vite5 + Vue3 + TS(strict) + Element Plus + Pinia + Vue Router + Axios。
- **形态**：monorepo——根目录为 Go 后端；`pharmacy-web/` 为前端 SPA。
- **Git**：远程 `https://gitee.com/luo-yinhe/pharmacy-management-system.git`；本地分支 `main` 跟踪 `origin/master`；推送 `git push origin main:master`；作者 vincentluo <yhkjsj@foxmail.com>。
- **提交惯例**：每次提交必须同步更新主页 `README.md`（docs/06 §8）；推送前若远端有新提交先 `git pull --rebase origin master`。

## 后端（迁移共 29 版：000001-000028）
- **模块**：auth/users、drugs/categories/interactions、suppliers、purchase、inventory（库存/调拨/拆零/盘点/预警/领用补发单）、prescriptions（全状态机+医嘱核对+给药途径+分批组）、patients/allergies/用药史、charge_records（一键计费/退药冲正/红冲/患者费用）、clinical_services、specialdrugs、pharmaservice、reports(6)、reference(5 目录查询+目录匹配)、operation_logs、port 二期接口。
- **角色（8）**：admin / pharmacy_director / pharmacist / doctor / clinic_nurse(跟诊护士) / pharmacy_nurse(药房护士) / buyer / finance；RBAC 按路由组强制（server.go Groups：DrugAdmin/Pharmacy/Clinical/Purchase/Report/Billing/Patient/PatientRead/Charge/UserAdmin）。
- **关键正确性**：金额整数分；FEFO+预占/实扣/释放（行锁+条件更新）；处方版本号乐观锁；麻精双人核对(4003)/拆零双人复核(2013)；退药冲正与退药同事务；GORM 更新用 Select("*")（避免布尔零值丢失）。
- **验证命令**：`go build ./...`、`go vet ./...`、`go vet -tags=integration ./...`（集成测试需 PG，CI 跑）、`go test ./...`、`gofmt -l .`、`golangci-lint run ./...`（.golangci.yml 排除 pharmacy-web）。
- **环境**：`make db-up`（docker-compose PG16+迁移）；种子用户 8 个（密码 admin123）；Swagger `/swagger/index.html`；CORS 由 `server.cors_allow_origins` 配置。

## 前端 pharmacy-web（P0-P6 全部完成）
- **页面**：登录、主布局(8 角色菜单)、工作台、患者（过敏史/用药史）、开方（**给药途径+分批配伍分组卡片**）、处方列表/详情（核对医嘱/审核/调配/发药/退药/一键计费）、药品（目录匹配）、分类、供应商、参考数据(5 Tab)、库存（补发登记单）、采购、计费（红冲/诊疗项目）、药学服务、特殊药品、报表(6)、系统管理。
- **基础设施**：`api/http.ts`（信封解包/401 跳登录/路由切换取消请求）；`v-permission` 按钮权限；`types/business.ts` 角色权限点与后端对齐；`types/generated/` 由 swagger 生成。
- **脚本**：`dev`、`type-check`、`lint`/`lint:fix`、`format`/`format:check`、`gen:types`（swagger2openapi + openapi-typescript）、`build`、`preview`。
- **CI**：`.github/workflows/frontend-ci.yml`；后端 CI 含 golangci-lint + domain 覆盖率≥85%。
- **验证**：`npm run lint && npm run format:check && npm run type-check && npm run build` 全绿。
