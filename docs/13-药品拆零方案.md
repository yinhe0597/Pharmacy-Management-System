# 13 药品拆零方案

> 本文档定义药房拆零的目标态完整方案，并逐项对照当前实现，给出出入/不足清单与实施路径。

---

## 一、拆零的业务定义

拆零 = 将大包装（盒/瓶）物理拆散为最小发药单位（片/粒/支）后按最小单位发药。

完整拆零能力覆盖以下环节：

| 环节 | 说明 |
|------|------|
| 主数据 | 是否可拆零、拆零单位、包装含量（pack_size）、拆零零售价、拆零进价 |
| 拆零操作 | 按盒拆零、开盒零头入账、拆零损耗（破损）登记 |
| 拆零库存 | 拆零柜批次库存独立管理，效期延续原盒 |
| 处方计价 | 整盒部分按盒价、零头部分按片价，金额精确 |
| 分配/发药 | 优先拆零库存，不足自动拆整盒补足（跨口径） |
| 退药 | 按原发药形态回补对应口径库存 |
| 盘点/预警/报表 | 拆零行与整盒行分别核算，汇总折算 LDU |

## 二、当前实现（v1）梳理

| 模块 | 当前实现 |
|------|---------|
| 主数据 | `drugs.is_split_allowed / split_unit / pack_size / split_retail_price / split_purchase_price`，拆零价在 Create/Update 时按 `round(价格/pack_size)` 公式推算 |
| 库存模型 | 双行：`(drug, location, batch, expiry, is_split)` 唯一；`is_split=false` 数量按盒，`true` 按片 |
| 拆零操作 | `Split(InventoryID, Packs)` 仅支持按整盒拆：整盒行 `-Packs`，拆零行 `+Packs×pack_size`；校验仅拆未预占的盒 |
| 处方计价 | 明细 `is_split` 决定口径：整盒行 `quantity`(盒)×盒价；拆零行 `quantity`(片)×片价；**一行只能二选一** |
| 预占/发药 | `reserveItemTx` 按 `item.IsSplit` **同口径** FEFO 选批次预占；发药消费预占 |
| 退药 | 按发药记录原批次回补（含拆零行） |
| 盘点/预警/报表 | 双行分别处理，汇总折算 LDU |

## 三、对照结论：出入与不足清单

### 3.1 正确性缺陷（高优先级）

| # | 出入/不足 | 影响 | 状态 |
|---|----------|------|------|
| C1 | **拆零行进价取自主数据而非批次实际进价**：`Split` 中拆零行 `unit_price = drug.SplitPurchasePrice`，而整盒行的 `unit_price` 是**该批次实际进价**。一品多商/价格变动时，拆零库存成本失真，批次毛利计算错误。 | 成本/毛利不正确 | 待修 |
| C2 | **一行内「整盒+拆零」混合发药无法表达、计价不精确**：如 36 片=1.5 盒，当前只能全按片价（`round` 累计误差）或拆两行（触发重复用药提醒）。与「整盒按盒价、零头按片价」的行业规则相悖。 | 计价精度、处方录入体验 | 待设计 |
| C3 | **分配强制同口径**：拆零库存不足时，即使整盒库存充足也报缺货，不能自动拆整盒补足；药师须手动拆零后重新提交。 | 发药效率、可用量误判 | 待设计 |

### 3.2 功能完整性不足（中优先级）

| # | 出入/不足 | 影响 | 状态 |
|---|----------|------|------|
| F1 | **仅支持按整盒拆零**，不支持「开盒零头入账」（现实已开盒剩 20 片）。拆零行数量被强制为 `pack_size` 的整数倍。 | 不贴合实际 | 待修 |
| F2 | **无拆零损耗登记**：拆零破损片数无法账务化（需与报损联动）。 | 损耗不可追溯 | 待修 |
| F3 | **拆零零售价不可配置**：药房常自定义拆零价以分摊损耗（如 24 片 2400 分，拆零按 105 分/片），当前公式强制推算。 | 定价灵活性 | 待修 |
| F4 | **无拆零操作单**：只有两条流水，无独立拆零单（含操作人/复核人/原因），麻精药品拆零审计维度弱。 | 审计 | 待设计 |
| F5 | **无拆零专项统计**（拆零量、拆零损耗、拆零毛利占比）。 | 经营分析 | 待设计 |

### 3.3 已正确/无需改动

- 拆零行效期延续原盒（批号效期不丢）。
- 仅拆「未预占」的整盒（已修复，防止破坏 `quantity>=reserved` 不变量）。
- 盘点/预警/报表按行核算并折算 LDU。
- 退药按原形态回补拆零行。
- 拆零操作单事务 + 条件扣减，无超拆。

## 四、目标态完整方案

### 4.1 主数据

- 拆零零售价：**默认公式推算，允许显式覆盖**（`split_retail_price` > 0 时尊重调用方值）。
- 新增一致性校验：`|split_retail_price×pack_size − retail_price| / retail_price > 阈值`（如 2%）时提示（允许覆盖场景放行）。
- 拆零进价：恒由 `round(批次实际进价 / pack_size)` 推导，不独立配置（成本侧不可人为调整）。

### 4.2 拆零操作（两类，统一为一接口）

```
SplitPacks   (inventoryID, packs)                    // 按盒拆，等价 SplitUnits(packs, packs×pack_size, 0)
SplitUnits   (inventoryID, boxes, units, damaged)    // 开盒零头入账 + 破损报损
```
约束：来源为可拆零药品的整盒行、仅拆未预占盒；`units + damaged == boxes × pack_size`（账目平齐）；
`units` 入拆零行（unit_price=round(整盒行实际进价/pack_size)）；`damaged>0` 时写 `waste` 流水（报损）。

### 4.3 处方计价（LDU 统一口径）

- 处方明细 `quantity` 统一以 **LDU（拆零单位）** 计，金额精确拆分：
  `boxes = quantity ÷ pack_size`，`units = quantity mod pack_size`
  `amount = boxes × retail_price + units × split_retail_price`
- `is_split` 由「强制口径」改为「建议形态」，供分配器参考。
- 兼容：不可拆零药品 `pack_size=1`，公式退化为 `quantity × retail_price`。

### 4.4 分配与发药（跨口径分配器）

```
分配(drug, location, ldu_qty):
  1. 优先拆零行 FEFO，逐行按可用 LDU 预占（行内数量=可用片数）
  2. 不足部分：整盒行 FEFO，按整盒预占（可用盒×pack_size 计入）
  3. 仍不足且存在整盒可拆 → 返回 shortage 明细 + 提示「可拆零补足 X 片」
发药确认前（调配环节）：
  - 对「拆零行不足、需由整盒拆出的余片」，在事务内执行 SplitUnits 再实扣
  - 或维持「预占时整盒不足即提示先拆零」的显式流程（一期二选一）
```

> 取舍：**显式拆零**（药师先拆零再提交，流程可控、可审计）与**自动拆零**（发药时自动拆，少一步操作、库存即时）。建议一期用「显式拆零 + 缺货提示」保证正确，二期评估自动拆零。

### 4.5 审计与统计（二期/后续）

- 拆零单 `split_orders`：操作人/复核人/原因/来源行/结果行，麻精药品强制双人。
- 报表：拆零量（片）、拆零损耗（片/金额）、拆零毛利（拆零收入 − 拆零成本）。
